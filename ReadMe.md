# HR Analytics Dashboard

## 📌 Overview
This project presents an **HR Analytics Dashboard** built in Excel to analyze key workforce metrics such as **attrition, job satisfaction, demographics, and education levels**. The dashboard provides interactive visualizations and KPIs to help HR teams make data-driven decisions.

---

## ✨ Features
- 📊 **Attrition Analysis**  
  Breakdown by department, job role, age group, and education level.
- 👥 **Workforce Demographics**  
  Gender distribution, marital status, and average age.
- ⭐ **Job Satisfaction Insights**  
  Overall rating and trends across employee groups.
- 📈 **Key KPIs**  
  - Total Employees  
  - Active Employees  
  - Attrition Rate  
  - Average Age  
- 🔍 **Interactive Filters**  
  Filter by education field and department for deeper insights.

---

## 🛠️ Tech Stack
- **Microsoft Excel** (Dashboard creation, charts, pivot tables)
- **Data Visualization** (bar charts, pie charts, KPIs)
- **HR Metrics** (attrition, demographics, satisfaction)

---

## 🚀 Use Cases
- HR teams can monitor attrition trends and job satisfaction.
- Managers can identify workforce challenges and improve retention.
- Supports **workforce planning** and **employee engagement strategies**.
